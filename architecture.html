🔑 핵심 아키텍처 결정 (권고안 — 민철 최종 컨펌 1건 대기): V2는 별도 서비스가 아니라 SkinSeoulFacade `apps/internal-api` 안의 새 도메인(`domain/wms2`) + 신규 Cloud SQL(PostgreSQL)로 짓는다. 이유 — ① 배포 파이프라인·인증(ApiKeyGuard/JWT)·모듈 패턴 재사용, ② V1(DDB)과 같은 프로세스에서 병행 운영 → 컷오버가 라우팅 스위치 수준, ③ 이미 회사가 Cloud SQL 운영 중. 프론트는 기존 AdminDashboard에 화면 8종(와이어프레임 확정본) 추가 — 신규 앱 없음.
